# 🧮 Simple Calculator

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.
This project performs basic arithmetic operations through an easy-to-use calculator interface.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal number support
* 🧹 Clear display button
* ⚡ Instant calculation
* ❌ Error handling for invalid expressions
* 🎨 Simple and clean calculator UI

## 🛠️ Technologies Used

* **HTML5** — Structure of the calculator
* **CSS3** — Styling and layout
* **JavaScript** — Calculator functionality and calculations

## 🧠 How It Works

The calculator uses JavaScript to handle button clicks and update the display.

### Display Input

The `activityToDisplay()` function adds the selected number or operator to the calculator display.

### Clear Display

The `clearDisplay()` function removes everything from the display.

### Calculate

The `calc()` function evaluates the expression entered by the user and displays the result.

It also uses error handling so that invalid expressions display:

```text
Error
```
